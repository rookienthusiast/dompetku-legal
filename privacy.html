Kebijakan Privasi Dompetku

Berlaku sejak 25 November 2026

Dompetku adalah aplikasi pencatat keuangan pribadi untuk Android. Halaman ini menjelaskan data apa yang diproses aplikasi, di mana data itu disimpan, dan bagaimana kamu mengendalikannya.

1. Data yang dicatat

Data yang kamu masukkan sendiri: dompet dan saldonya, transaksi (pemasukan, pengeluaran, transfer), penyesuaian saldo, rencana anggaran dan amplop, tagihan dan cicilan, serta piutang (termasuk nama orang yang kamu tulis). Aplikasi juga menyimpan pengaturan seperti tema dan jam pengingat.

2. Di mana data disimpan

Semua data tersimpan di database lokal di HP-mu. Dompetku tidak punya server, tidak membutuhkan akun Dompetku, dan tidak memuat iklan, analitik, atau pelacak pihak ketiga. Pengingat adalah notifikasi lokal yang dijadwalkan di HP.

3. Cadangan Google Drive (opsional)

Fitur ini mati sampai kamu menekan Hubungkan Google di Pengaturan. Bila diaktifkan:

  • Aplikasi meminta satu izin saja, drive.file: aplikasi hanya dapat membuat, membaca, mengubah, dan menghapus file yang dibuatnya sendiri. Aplikasi tidak dapat melihat file lain di Google Drive-mu.
  • Aplikasi mengunggah salinan cadangan datamu (file JSON) ke folder Dompetku di Google Drive milikmu, dan dapat menulis spreadsheet Dompetku berisi data yang sama untuk kamu baca. Aplikasi menyimpan 30 cadangan terbaru dan menghapus yang lebih lama.
  • Data dikirim langsung dari HP-mu ke Google melalui koneksi terenkripsi. Data itu tidak dikirim ke pihak lain dan tidak disimpan di server mana pun selain akun Google-mu.
  • Aplikasi hanya membaca file cadangan itu saat kamu memilih Pulihkan dari Google Drive.
  • Alamat email akun Google disimpan di HP hanya untuk ditampilkan di Pengaturan.

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh Dompetku mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

4. Berbagi data

Dompetku tidak menjual, menyewakan, atau membagikan datamu kepada siapa pun. Data hanya meninggalkan HP bila kamu sendiri mengekspor atau membagikan file cadangan, atau mengaktifkan cadangan Google Drive ke akunmu sendiri.

5. Mengendalikan dan menghapus data

  • Data di HP: menghapus aplikasi menghapus seluruh datanya dari HP.
  • Menghentikan cadangan: Pengaturan → Putuskan Google Drive menghentikan unggahan dan mencabut izin aplikasi. Izin juga dapat dicabut di myaccount.google.com/permissions.
  • File di Google Drive: folder Dompetku dan isinya milikmu dan dapat kamu hapus kapan saja dari Google Drive.

6. Perubahan kebijakan

Bila kebijakan ini berubah, tanggal berlaku di atas diperbarui.

Summary in English

Dompetku is a personal finance app for Android. All data stays in a local database on the device; there is no Dompetku server, account, advertising or analytics. If the user turns on the optional Google Drive backup, the app requests only the drive.file scope and uploads backup files (and a read-only spreadsheet copy) to a Dompetku folder in the user's own Drive. It cannot see any other Drive files, does not share data with anyone, and reads the backups back only when the user chooses to restore. Dompetku's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access in the app or at myaccount.google.com/permissions and delete the files from Drive at any time. Contact: arhamninizar@gmail.com
